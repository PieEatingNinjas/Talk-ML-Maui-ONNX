# ML.NET has two sides
- **AutoML**: tools that generate models and code for you
  - Model Builder (GUI in Visual Studio)
  - CLI tool (```dotnet tool install -g mlnet```)
- **SDK**: build custom ML pipelines in code and run the models you’ve trained
	- NuGet package: ```Microsoft.ML```
