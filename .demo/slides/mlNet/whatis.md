# What is ML.NET (and why should you care?)
-	Microsoft’s open-source ML framework for .NET devs
-	Train, evaluate, and run models right in C#/F#
-   No need to switch over to Python or R
-	Plays nicely with other .NET stuff
    *   Visual Studio, NuGet, LINQ, ASP.NET, MAUI, Blazor, etc.
