# What this means in practice
## What ML adds
- Shifts decision-making from rules to learned behaviour
- Solves problems without clear heuristics
- Forces you to think in data quality & metrics, not just code correctness

## What ML.NET enables
- Integrate ML directly into existing .NET apps
- Start fast with AutoML, then refine with domain-specific pipelines
- Use pre-trained models through ONNX
- Run anywhere .NET runs
